


Website Sekolah

Deskripsi

Website Sekolah merupakan aplikasi berbasis website yang dibuat untuk menyediakan informasi mengenai sekolah secara lebih mudah, cepat, dan terstruktur. Website ini dirancang agar pengguna dapat mengakses berbagai informasi sekolah melalui satu platform.

## Cara Menjalankan Project
Clone repository dari GitHub menggunakan perintah:
git clone https://github.com/andhinn-r/website-profil-sekolah

masuk ke folder project:
cd website-profil-sekolah

Install seluruh library
npm install

Konfigurasi Environment
buat file: 
.env

masukkan konfigurasi Supabase
NEXT_PUBLIC_SUPABASE_URL=[Url supabase Anda]
NEXT_PUBLIC_SUPABASE_ANON_KEY=[Anonkey supabase anda]

install supabase dalam terminal 
npm install @supabase/supabase-js

Menjalankan Development Server
npm run dev

Membuka Website
http://localhost:3000
