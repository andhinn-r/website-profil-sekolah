## 📖 Deskripsi

**Website Sekolah** merupakan aplikasi berbasis website yang dibuat untuk menyediakan informasi mengenai sekolah secara lebih **mudah**, **cepat**, dan **terstruktur**. Website ini dirancang agar pengguna dapat mengakses berbagai informasi sekolah melalui satu platform terpadu.

---

## 🛠️ Teknologi yang Digunakan

- **Next.js** — Framework React untuk pengembangan frontend dan backend
- **Supabase** — Database dan backend service
- **TypeScript** — Bahasa pemrograman utama
- **Node.js & npm** — Runtime dan package manager

## 🚀 Cara Menjalankan Project

Ikuti langkah-langkah berikut untuk menjalankan project di lingkungan lokal Anda.

### 1️⃣ Clone Repository

```bash
git clone https://github.com/andhinn-r/website-profil-sekolah
```

### 2️⃣ Masuk ke Folder Project

```bash
cd website-profil-sekolah
```

### 3️⃣ Install Seluruh Library

```bash
npm install
```

### 4️⃣ Konfigurasi Environment

Buat file **`.env`** pada root folder project, lalu isi dengan konfigurasi Supabase berikut:

```env
NEXT_PUBLIC_SUPABASE_URL=[Url supabase Anda]
NEXT_PUBLIC_SUPABASE_ANON_KEY=[Anonkey supabase anda]
```

### 5️⃣ Install Supabase Client

```bash
npm install @supabase/supabase-js
```

### 6️⃣ Menjalankan Development Server

```bash
npm run dev
```

### 7️⃣ Membuka Website

Buka browser dan akses:

```text
http://localhost:3000
```
